### Question 1: JavaScript --- Number Guessing Game \[10 Marks\]

Create a JavaScript game where a user tries to guess a secret number
generated by your code.

**index.html** - Create a text field (`input type="text"`) to take the
user's guess and a submit button. - Below the submit button, add a label
field to show feedback and results.

**script.js** 1. Generate a random secret number between 500 and 5000.
2. Take the user's guess from the input field in the HTML file. 3.
Inside a function: - Compare the user's guess to the secret number. -
Display `Too high!` or `Too low!` in the feedback area of the web
page. - If the guess is correct, display `Correct!` and optionally
disable the input field to prevent further guesses. - Keep track of the
number of guesses the user has made. - If the user runs out of guesses
(after 5 attempts), display `Out of guesses!` and optionally disable the
input field.

**Sample cases**

### Question 2: PHP --- Pizza Party Calculator \[10 Marks\]

It's the end of the Web Programming course, and we want to celebrate it
by having a pizza party. Figure out how many pizzas to order and how
many slices will be left over.

Write a PHP function that takes three integers as input: - Number of
students in the class - Number of slices each student wants - Number of
slices each pizza has

The function should calculate: 1. The minimum number of pizzas needed to
ensure every student gets enough pizza. You must order whole pizzas; you
cannot order fractions of pizzas. 2. The number of pizza slices left
over after all students have had their fill. 3. If each pizza costs
**1050 BDT**, the money wasted based on the leftover slices.

**Sample input and output**

  -----------------------------------------------------------------------
     Students  Slices per  Slices per       Total    Leftover      Wasted
                  student       pizza      pizzas      slices money (BDT)
  ----------- ----------- ----------- ----------- ----------- -----------
           10           3           8           4           2       262.5

            7           2           6           3           4         700

           12           2           4           6           0           0
  -----------------------------------------------------------------------

### Question 1: JavaScript --- Password Strength Checker \[10 Marks\]

Create a JavaScript application where users can test their password
strength and get real-time feedback.

**index.html** - Create a password input field
(`input type="password"`), a **Check Strength** button, and below that a
label field to display strength feedback and scoring results.

**script.js** 1. Generate a target strength score of 100 points for a
`Very Strong` password. 2. Take the user's password input from the HTML
file. 3. Inside a function, calculate password strength using these
criteria: - Length: +10 points for every 2 characters (minimum 6
characters required). - Uppercase letters: +15 points if present. -
Lowercase letters: +15 points if present. - Numbers: +20 points if
present. - Special characters (`!@#$%^&*`): +25 points if present. 4.
Display strength levels: - `Very Weak` (0--30) - `Weak` (31--50) -
`Medium` (51--70) - `Strong` (71--90) - `Very Strong` (91+) 5. If the
password reaches 100+ points, display `Perfect Password!` and show a
success message. 6. Keep track of how many attempts the user has made.
7. If the user makes more than 8 attempts without reaching `Strong`
level, display `Need practice!` and suggest password tips.

**Sample input and output**

  Password            Output
  ------------------- -------------------
  `abc`               Very Weak
  `hello123`          Weak
  `Strong@Pass`       Strong
  `Perfect@Pass123`   Perfect Password!
